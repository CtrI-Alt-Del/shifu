# Shifu

Shifu is a guided learning application. The web application lives in
`apps/web` and is managed as a standalone pnpm project; this repository does
not use a package-manager workspace or root-level orchestration.

## Web application

Run commands from the web app directory:

```sh
cd apps/web
pnpm install
pnpm dev
```

The app is available at `http://localhost:3000`.

## Validation

```sh
cd apps/web
pnpm generate-routes
pnpm check:types
pnpm build
pnpm preview
```

`src/routeTree.gen.ts` is generated by TanStack Router. Route files belong in
`apps/web/src/routes`, while feature UI belongs under the corresponding
`apps/web/src/ui/<module>` boundary.
