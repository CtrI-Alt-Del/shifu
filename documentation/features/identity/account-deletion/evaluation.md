# Lessons Learned

| Lesson | Supporting finding / evidence | Documentation action or disposition |
| --- | --- | --- |
| A durable retry must include every required participant, including technical identity cleanup owned by the BFF. | ACH-05; opaque event and focused job tests | Added the worker and `SHIFU_BFF_BASE_URL` wiring to Spec revision 3. |
| Queue admission itself needs the account barrier; rejecting delivery later does not remove a newly persisted personal payload. | ACH-06; 5 queue tests | Communication queue validates account status under the shared barrier before writing. |
| An ambiguous external effect stays fail-closed until owner evidence confirms the result and no remote operation remains live. | ACH-09; PostgreSQL reconciliation integration | Reconciliation now enforces evidence, a 30-minute age and explicit quiescence confirmation. |
