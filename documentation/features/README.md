# Feature specifications

Feature SDD artifacts live at `<module>/<feature>/` and follow
[`../sdd.md`](../sdd.md). Start from the files in
[`../templates/sdd`](../templates/sdd); do not copy canonical PRD prose into the
repository. Every Spec records the Confluence content ID/version and traces its
local `RF-*` and `CA-*` identifiers to Shifu `RP-*` and `JN-*` identifiers.
