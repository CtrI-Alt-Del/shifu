## Lessons learned and authority disposition

ACH-01–20 are resolved; no blocking finding remains. Coverage must be based on executable, trusted per-Concept evidence (ACH-02/07/15), and a persisted recommendation target is needed for deterministic continuity (ACH-05/13). Diagnostic replay, timeout and privacy are part of the account-owned transaction rather than browser state (ACH-06/08/12/14/16). Unknown Concept coverage must not be presented as official numeric progress (ACH-11). An explicit destructive local seed reset must also clear pending outbox events from deleted attempts (ACH-17); this is now enforced by the seed path and its disposable repeat test. The shared-port browser setup issue was isolated and cleared without changing implementation (ACH-18). CI merge reconciliation and asynchronous job-test ordering are delivery-specific corrections (ACH-19/20) already captured by the final checks; no global Architecture, Rules, Design or Tooling update is warranted. The missing README warning, occupied default Inngest callback port and shared Home query warning are environment/package or excluded-surface facts, not reusable product authority changes. No external authority change is pending.
