# Lessons Learned

| Lesson | Supporting finding / evidence | Documentation action or disposition |
| --- | --- | --- |
| Adding a tab to a fixed-width tab bar is a responsive change, not just a list edit. A four-item bar that fits desktop can push the whole page wider at 375 px, and nothing in the unit or route suites catches it — only a real narrow-viewport measurement does | ACH-01, EV-15, EV-16 | No authority change proposed. The Spec already required the narrow-viewport check (CA-23/VM-03) and it is what caught this; the lesson is that the check must measure `scrollWidth`, not just look at a screenshot |
| A mocked-port use-case suite cannot observe which account id a repository was called with, so account scoping needs an explicit call assertion to be covered at that boundary | ACH-02, EV-12 | No authority change proposed; recorded here because the same blind spot applies to every mocked-repository read use case in the repository |
