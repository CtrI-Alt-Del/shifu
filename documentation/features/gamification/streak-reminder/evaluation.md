# Lessons Learned

| Lesson | Supporting finding / evidence | Documentation action or disposition |
| --- | --- | --- |
| Real-stack manual runs find concurrency defects that mocked and per-test-container runs do not; a first-practice-day journey is worth keeping. | ACH-02, EV-28 | No documentation change now. Candidate for a testing-rule note. |
| A shared Playwright decoder that maps seroval constants to `undefined` hides booleans; do not widen shared helpers without running their other consumers. | EV-27 | Feature-specific; no rule change. |
| A skipped record consumes a unique-per-day slot, so demo tooling needs its own reset path or the cause is hard to retest. A "Completed" run in Inngest does not show that a push was sent; read the reminder and delivery rows. | ACH-13, EV-31 | Feature-specific; noted in `tooling.md`. |
| Poe `cmd` tasks need `${arg}` in the command to pass positional arguments. | ACH-03 | Feature-specific. |
| A seeded learner's streak ages out, so the demo command refuses it as not eligible once the last practice day is older than yesterday. The refusal message does not say why. | VM-03 manual run 2026-11-19 | Feature-specific. Candidate follow-up: make the message name the failed rule. |
| A host allowlist must read the raw address, not a URL parser's result: parsers disagree on backslashes and user info, and a disagreement lets another host receive the request. | ACH-15, ACH-20, EV-41 | Feature-specific; recorded in the Spec's `TrustedPushEndpoint` contract and in `architecture.md`. |
| A suite aimed at a static public script (service worker) breaks the plugin-test rule; prove it through the page that registers it, in a real browser. Headless shell denies notifications and Playwright's Chromium has no push backend, so use full Chromium and CDP `ServiceWorker.deliverPushMessage`. | ACH-16, EV-38 | Candidate note for the testing rules; no rule change now. |
| The test-integrity script is not part of CI, so a test file outside its boundaries can reach a published PR unnoticed. | ACH-19 | Open as a limitation: the user chose to allow the eval boundary; running the script in CI was not requested. |
