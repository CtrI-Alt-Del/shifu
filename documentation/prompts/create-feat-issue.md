# Create a Jira feature issue

Use Atlassian Shifu MCP only when issue creation is explicit. Read the complete
PRD and check Jira for duplicates. Create a concise `SHI-*` issue with module,
outcome, linked `RP-*/JN-*`, scope, exclusions, dependencies, risks, expected
validation, canonical PRD, and existing Spec.

Do not invent `RF/CA`; `create-spec` owns those. Issue creation never changes
PRD delivery state. Read the issue back and report its key and URL.
