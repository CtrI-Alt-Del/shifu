# Shifu workflow prompts

These prompts operationalize [the Shifu SDD workflow](../sdd.md). They inherit
`AGENTS.md`, repository authorities, the selected Rule Pack, and the complete
canonical Confluence PRD whenever product behavior is involved.

| Prompt | Purpose |
| --- | --- |
| [create-spec](create-spec-prompt.md) | Create a contract from Confluence requirements |
| [create-plan](create-plan-prompt.md) | Plan complex implementation |
| [implement-spec](implement-spec-prompt.md) | Implement and collect evidence |
| [conclude-spec](conclude-spec-prompt.md) | Verify and close delivery |
| [create-prd](create-prd-prompt.md) | Explicitly create or revise a Confluence PRD |
| [create-feat-issue](create-feat-issue.md) | Create a Jira feature issue |
| [create-bug-report](create-bug-report-prompt.md) | Diagnose a defect |
| [create-bug-issue](create-bug-issue-prompt.md) | Create a Jira bug |
| [create-refactor-issue](create-refactor-issue-prompt.md) | Create a Jira refactor task |
| [commit-code](commit-code-prompt.md) | Create scoped commits |
| [create-pr](create-pr-prompt.md) | Open or update a delivery PR |
| [resolve-pr-feedback](resolve-pr-feedback-prompt.md) | Route review feedback |
| [increase-test-coverage](increase-test-coverage-prompt.md) | Add behavioral tests |
| [create-release-pr](create-release-pr-prompt.md) | Promote `main` to `production` |
