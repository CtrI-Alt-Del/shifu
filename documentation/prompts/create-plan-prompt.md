# Create an implementation Plan

Read the ready Spec and all cited authorities. Use a Plan only for cross-layer,
cross-module, migration-heavy, risky, or parallel work.

Create colocated `plan.md` from the canonical template. Every step identifies
its `RF-*/CA-*`, exact files or layers, dependencies, ownership, risks, Rule
Pack, and `CI-*/VM-*` validation.

The Plan is not a second Spec. It must not add requirements, change criteria, or
mutate Confluence. Use only verified paths and commands. Set `in_progress`
when implementation starts and `completed` only after accepted evidence.
