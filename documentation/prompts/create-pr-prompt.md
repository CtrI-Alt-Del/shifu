# Create or update a pull request

Inspect branch, worktree, commits, remote, existing PR, Jira, Spec, Plan,
Evaluation, and validation. Follow the branch strategy; never open from
`main` or `production`. Use `gh` when explicitly requested to publish and
target `main` for normal delivery.

Use a plain title. The body summarizes outcome/scope and links `SHI-*`,
canonical PRD/`RP-*`, Spec/`RF-*/CA-*`, validation, manual checks,
screenshots, migrations, risks, and remaining work. Report Evaluation
disposition without implying Confluence changed.

Read the PR back and report URL, CI, and review state.
