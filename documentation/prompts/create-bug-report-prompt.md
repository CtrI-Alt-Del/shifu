# Create a bug report

Diagnose without fixing. Read applicable rules, implementation, evidence,
existing Spec/Evaluation, Jira, and the complete PRD when behavior is involved.
Record expected/actual behavior, reproduction, environment, severity, module,
affected boundaries, evidence, likely cause, and regression risk. Trace real
`RP/RF/CA` IDs without inventing them.

Route to an unchanged Spec correction, a new change Spec, or direct maintenance
only when behavior is unaffected. Do not edit code, Jira, Confluence, or SDD
status from this prompt.
